# Locker Room Management System

## Overview
This project is a Locker Room Management System developed to manage locker allocation, user access, booking, and monitoring efficiently.

## Technologies Used
- Python
- MySQL
- HTML/CSS
- Flask / Django
- SQLite

## Features
- Locker allocation and management
- User authentication
- Booking system
- Secure access monitoring
- Database management
- Real-time locker status tracking

## Modules
1. User Login and Registration
2. Locker Booking
3. Locker Availability Tracking
4. Admin Management
5. Database Storage
